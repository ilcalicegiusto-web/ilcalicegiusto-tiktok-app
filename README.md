# n8n Social Automation

This project contains automation workflows built with n8n.

The goal is to automate the creation and publishing of short-form video content
(e.g. clips derived from podcasts or educational content) to social platforms
such as TikTok and Instagram.

## Features
- Automated content generation
- Scheduled publishing
- Original content only
- No user data collection
- No advertising or spam behavior

## Usage
This repository is intended for internal automation and testing purposes.
