Privacy Policy

Last updated: February 2026

This web application ("Service") is operated by Il Calice Giusto.

1. Data Collected

When users authenticate via TikTok Login Kit, we may receive the following data: open_id, display name, avatar URL and access token, as permitted by TikTok API scopes.

2. Purpose of Processing

Data is used exclusively to enable automated publishing of video content to the user's TikTok account via the TikTok Content Posting API.

3. Data Storage

Access tokens are stored securely and are not shared with third parties. No data is sold.

4. Legal Basis

Processing is based on user consent provided through TikTok OAuth authorization.

5. Data Retention

Data is retained only as long as necessary to provide the service or until the user revokes authorization.

6. Third-Party Services

This Service integrates with TikTok for Developers APIs. Use of TikTok is subject to TikTok's own Privacy Policy.

7. User Rights

Users may request deletion of their data or revoke access at any time.
