Il Calice Giusto – TikTok Automation

This web application allows the account owner of "Il Calice Giusto" to authenticate via TikTok Login Kit and automate the publishing of short-form podcast clips using n8n workflows.

How it works:
  1. User authenticates using TikTok Login Kit (OAuth).
  2. The app receives an authorization code and exchanges it for an access token.
  3. The access token is securely stored for automation use.
  4. n8n workflows generate short video clips from podcast episodes.
  5. The Content Posting API uploads the video as a draft to TikTok.
